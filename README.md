# Incarus
Game created for TCSS 360, at the University Of Washington Tacoma.


## Controls:
* Movement keys are: W, A, S, D.
* Change Room Keys are: Up-Arrow, Down-Arrow, Left-Arrow, Right-Arrow.
* Attack button: Space.
* Use potion button: Left shift.
* Print Potion amount button: E.
* Print oop pilers left button: Q.


## How to win:
To win the game you must find every oop piler, they randomly spawn throughout the dungeon. But watchout some rooms are trapped, and the Darklords minions are within the dungeon. The Darklord himself is also lurking within, be careful or you might die.
